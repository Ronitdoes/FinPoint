# Step 25 — Audit Trail & Case Timeline (Completion & Immutability)

## Objective

Complete the audit subsystem: enforce append-only guarantees at the DB role level, backfill any timeline gaps from earlier steps, expose the unified case-timeline API merging case_events with linked entities, and add the audit query API for compliance review.

## Why this step exists

Spec 01 §18 requires every sensitive action to generate an audit event with a specific field set, and §17 requires the per-case timeline ("one of the strongest demo features"). Steps s-10→s-24 emitted events through shared helpers; this step closes coverage gaps, makes immutability structural rather than conventional, and ships read APIs for dashboard/compliance.

## Requirement Coverage

- Spec 01 §17 case timeline; §18 audit trail fields + "Do not store secrets or unnecessary customer data"
- Spec 03 §11 "Audit records immutable to normal operators"
- Spec 00 Pillar D: "Why did the system stop?" must be answerable from records

## Prerequisites

- s-05 audit/case_events tables; emitters used across s-10–s-24; s-09 auth

## Requirements

1. Coverage verification script: walks terminal cases in test DB and asserts required event sequence present per surface (e.g., payment: PAYMENT_FAILED→RISK_CALCULATED→AI_DECISION_CREATED→POLICY_ALLOWED|POLICY_REJECTED→WORKFLOW_STARTED→…terminal). CI-runnable against seeded fixtures.
2. Immutability hardening:
   - dedicated DB roles: `app_rw` (current), `audit_writer` INSERT-only on audit_logs/case_events, revoke UPDATE/DELETE from app role on those tables
   - trigger guard `BEFORE UPDATE OR DELETE → RAISE EXCEPTION` as belt-and-braces
   - repositories already insert-only (s-06) — now enforced structurally
3. PII sweep on stored metadata: automated scanner rejecting email/phone/card patterns outside allowlisted masked fields.
4. APIs below incl. cursor pagination and actor filters.
5. Retention policy config: retention job skeleton (archive rows >N months to cold storage table `audit_archive` — execution deferred to ops step s-34 but schema+job stub now).

### Timeline merge logic

`GET /cases/:id/timeline` returns unified chronological feed assembled from:

```text
case_events (primary spine) LEFT JOIN enrichments:
  ai_decisions      → AI_DECISION_CREATED entries gain diagnosis/actions summary
  policy_evaluations→ POLICY_* entries gain verdicts
  messages          → *_SENT entries gain template/status
  payment_attempts  → PAYMENT_RETRY_* entries gain attempt results
  human_tasks       → HUMAN_TASK_CREATED / HUMAN_DECISION_RECORDED gain task info
Shape: {id, at, type, actor:{type,id}, description, data} — data redacted per allowlist
```

## API Contracts

```text
GET /cases/:id/timeline?types=&from=&to=&limit=100&cursor=
Auth role≥VIEWER → {items:[TimelineEntry], nextCursor}

GET /audit?tenant-scoped&case_id=&actor_type=&event=&from=&to=&limit=&cursor=
Auth ADMIN only (compliance surface) → raw audit entries
403 FORBIDDEN otherwise
```

## State Transitions

None new.

## AI Behavior

AI_DECISION_CREATED timeline entries embed decision summary (cause/confidence/top action/prompt_version) — enough for the demo narrative and audits without exposing snapshots.

## Reliability

Emission helpers were fire-on-DB-success patterns; coverage checker catches silent gaps. Trigger-based immutability survives future repo mistakes. Backfill tooling: one-off script mapping orphaned entities (messages/attempts without timeline rows) into reconstructed entries flagged `reconstructed:true`.

## Security Considerations

ADMIN-only raw audit access; VIEWER sees timeline via case route (business view) — separation documented. No secrets anywhere in metadata (scanner enforces).

## Observability

Metric audit_write_failures_total (alert-worthy if >0 — means app role regression); coverage check result logged in CI summary.

## Tests

- Immutability: app-role UPDATE/DELETE attempts → SQL exception (integration w/ real roles).
- PII scanner catches planted violations.
- Timeline API: ordering, enrichment fields present, pagination, cross-tenant 404.
