# AI Revenue Recovery Project Blueprint

This folder contains the product brainstorm and implementation blueprint for an AI Revenue Recovery platform.

## Files

- `00-brainstorm-and-product-vision.md` — product thesis, differentiators, roadmap, expansion ideas, metrics.
- `01-implementation-0-to-100.md` — the primary build guide from an empty repo to a production-style demo.
- `02-architecture-and-domain.md` — service boundaries, domain model, events, policies, workflows, APIs and security boundaries.
- `03-mvp-build-spec.md` — concrete MVP scope, demo scenarios, schemas, acceptance tests and operational requirements.

## Recommended reading order

1. Product vision
2. 0-to-100 implementation
3. Architecture/domain
4. MVP build specification
